Las fórmulas con tus números

Son las fórmulas de M/M/c con c = 2, simplificadas. Se recalculan al mover λ o μ.

Forma general de P0 para M/M/c: P0 = [ Σn=0..c−1 rⁿ/n! + rc/(c!·(1−ρ)) ]⁻¹ con r = λ/μ. Con c = 2 queda (1−ρ)/(1+ρ). Todas exigen ρ < 1, es decir λ < 2μ.

Cómo funciona la simulación

Primero se simula toda la franja en un instante; luego la escena 3D reproduce el resultado minuto a minuto.

  1. Genera las llegadasEl tiempo entre un cliente y el siguiente es exponencial: −ln(1 − U)/λ, donde U es un número al azar entre 0 y 1. Así las llegadas forman un proceso de Poisson.
  2. Elige empleadoSi E1 está libre lo atiende E1; si no, E2. Si los dos están ocupados, el cliente espera en la fila única y pasa con el primero que se desocupe.
  3. Calcula los tiemposInicio = el mayor entre su llegada y la hora en que se libera el empleado. Fin = inicio + tiempo de atención exponencial con tasa μ.
  4. MideWq = inicio − llegada y W = fin − llegada. Lq, L y Pn salen de cuánto tiempo hubo n personas en el local, dividido entre la duración de la franja.
  5. Repite y promediaSe corren varias réplicas con semillas distintas. La misma semilla siempre da el mismo resultado, así se puede repetir en la sustentación.
// Simula una franja: devuelve llegada, empleado, inicio y fin de cada cliente
function simularFranja(lamH, muH, dur, semilla) {
  const azar = crearAleatorio(semilla);
  const exponencial = tasa => -Math.log(1 - azar()) / tasa;
  const lam = lamH / 60, mu = muH / 60;   // pasar a clientes por minuto
  const libre = [0, 0];                   // minuto en que se libera E1 y E2
  const clientes = [];
  let t = 0;
  while (true) {
    t += exponencial(lam);                // llega el siguiente cliente
    if (t > dur) break;                   // se cerró la franja
    let e;
    if (libre[0] <= t) e = 0;             // E1 libre
    else if (libre[1] <= t) e = 1;        // E2 libre
    else e = libre[0] <= libre[1] ? 0 : 1; // espera al primero que se libere
    const inicio = Math.max(t, libre[e]);
    const fin = inicio + exponencial(mu);
    libre[e] = fin;
    clientes.push({ id: clientes.length + 1, llegada: t, empleado: e, inicio, fin });
  }
  return clientes;
}
